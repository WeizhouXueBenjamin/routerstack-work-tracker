## 实际覆盖

- 新增、同日多工作、App 空白/0、中文及特殊字符备注，保存重开后原始值保持。
- 无 Invoice 编辑、删除前序记录、过滤后提交，其他记录不被覆盖。
- 草稿离开提醒、取消切换/导入、下载待确认；旧导出确认不清除新修改。
- 保存快照等待 close；写入/关闭失败、取消、原文件和同一文件句柄覆盖拦截。
- 非法类型、表头、配置、日期时间、版本、重复 Invoice、超容量与附加列拒绝导入，当前记录及草稿保留。
- Sheet 重排、内部 relationship 重命名、稀疏空行、有效/损坏 shared formulas。
- 旧 2.0 只读、升级逐笔预览与取消；Config 变化整周期预览与另存快照更新。
- 部分余额、连续结转、空白周期；结转不计新工作，不累加金额和备注。

Excel 回归使用 15 条工作及 1 条 Carryover，包括 18:00–06:00、混合短工、Lunch、Extra、半分正负舍入及 05:59–06:01 分钟边界。实际执行：Tool 生成 → Excel 重算/修改/重排/另存 → Tool 校验并预览 Config 变化、另存 → Excel 再重算；另验证 Excel 另存后的 2.0 shared formulas。所有产物位于系统临时目录，不含真实财务数据。
