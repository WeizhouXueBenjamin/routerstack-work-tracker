恢复验证日期：2026-11-12（用户时区 Pacific/Auckland）。对象为基于 `cacae26f0499f3c1d08d010eb015565068b649af` 的本地未提交改动。中断前已完成实现、Chromium/Chrome 完整回归及桌面 Excel 回归；恢复后从缺少最终结果的 Edge 继续，并检查最后的清单文字与总览显示调整。

### 已完成的修复与功能

- 原文件保护覆盖整个浏览器会话；重开成功导出的版本、再通过无句柄输入打开文件，都不会清空此前的保护。
- 结转选择和金额纳入草稿提醒；关闭、ESC、离开页面均保护未生成内容。生成期间锁定输入和关闭，取消或写入/close 失败保留草稿；确认替换文件后不遗留旧结转候选。
- inline/shared 富文本只读取正文，不把 `rPh` 注音提示加入备注。桌面 Excel 回归进一步发现原始字符串首部空白丢失，已改用 `xml:space="preserve"` 的 inline string；严格文本断言保持不变。
- 月度视图只统计当前 XLSX，按 Job 原工作日期分月；跨月夜班整项归于原日期。确认结转单列，不进入新工作预计或工时。
- 提醒筛选覆盖差额、Invoice 待补、App 待填；月度合计不随筛选缩水，保存始终导出全量记录。App 空白与明确的 0 分开；无可比项时显示“—”。页面文件总览也按此口径将工作预计与结转分开。
- Tim 清单默认包含所选月份差额及待补项，另列本文件确认结转；也可明确选择当前可见或全部工作。文本保留来源、估算规则、范围与未保存提示，只复制到本机，不自动发送。
