## 优先顺序

1. 守住数据完整性和 XLSX 兼容：全部表、身份、来源、金额、保存状态不丢失，不启动 schema 重设计。
2. 完成下面的快速录入任务，减少日常重复操作。
3. 按真实使用问题小改估算解释、App 差异/缺资料提醒和 Tim 清单，优先复用现有功能。
4. 轻量遗留事项与换期：保留人工确认余额/问题及提醒来源。现有批次覆盖条件尚未简化；调整前另评估旧表/关联/待补/审计兼容，不悄悄改变携带范围。

暂缓和排除项统一在 Goal 维护，不随旧 A1–A3/B/C 计划重新激活。

## 下一实施任务：快速连续录入

服务目标一；数据保护同时守住三个目标。现有功能要求每笔重复日期/费率、重新找周期，新增负担应限于一次配置及必要文件权限，不增加财务必填项。

| 顺序 | 范围 | 验收条件 |
|---|---|---|
| 1 | 安全重开最近使用周期 | 重新读取实际 XLSX；权限失效、移动/删除或版本不明可重选；保留未保存保护，不凭文件名声称最新，不自动覆盖/保存 |
| 2 | Default Hourly Rate | 复用已有 Config 字段；未配置留空，用户填实际值；单笔覆盖不改默认，改默认不改历史 Rate；随 XLSX 保存重开 |
| 3 | 连续表单 | 成功提交后保留当前 Work Date、恢复默认 Rate；清空 Invoice、Start/End、Lunch、App、Extra、Notes 和本笔观察输入，不复制已有 Site；失败留稿，编辑旧工作后恢复新增上下文 |
| 4 | 键盘与保存 | Tab/适当 Enter，成功后聚焦下一笔；Notes 换行、中文输入法不误提交；新增仍未保存，下载待确认、write/close 失败及旧快照确认不清新修改 |

最近文件的浏览器机制、权限和 file:// 降级尚未选定；仅可保存必要便利引用/设置，不复制工作账本。新增持久化机制须说明与当前实现的区别。默认值须走完整 Bundle 校验/命令，不绕过受控表；若确需改 schema，先说明兼容方案并另行确认，不顺带建设预设系统。

## 验证与完成

- 先核对工作区，使用合成数据运行 npm run check；解析/导出改动必须跑浏览器新增 → 保存 → 重开 → 结转，逐字段核对全部表、身份、确认金额和来源。
- 快录验证：历史日期连续两笔、默认空白/有值/单笔覆盖、改默认不改旧工作、编辑后继续新增、Tab/Enter/输入法、文件权限失败与草稿/保存状态。
- 兼容验证：App 空白/0、旧版只读及升级取消/接受、Config 变化预览、坏文件原子拒绝、ID/引用/容量、连续结转、历史不计新收入；保留既有复杂功能测试以守住历史数据。
- 模板/公式/schema 变更另跑桌面 Excel 重算、原始字段/Config 编辑、排序、shared formulas 及 Tool 往返；浏览器不替代 Excel。
- 完成说明记录实际代码、覆盖行为、环境与限制；未跑标“未验证”，不以测试数量或历史结果代替本次验收。
