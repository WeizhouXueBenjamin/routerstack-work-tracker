| 新周期 | 点击按钮勾选具体 Invoice，手动输入已证实的剩余金额 | **已采用**；不能按金额差自动迁移 |

## 跨版本注意

- **V1**：基于旧手工工作表做的公式/汇总优化；历史记录已按当时的数据保存，但用户后来明确表示不需要持续迁移历史。
- **V2**：全新周期从空白开始；旧 V1 / 原 Payslip 归档。不能因为有新工具就自动变更/吞掉原始历史。
- **v0.2.0 repo**：V2 单页离线应用的可维护源码拆分和测试基线；尚不是“所有未来计划已完工”。

## 设计取舍

1. **逻辑分离 ≠ 数据复制。** 工具可升级，事实仅有一份。数据读写必须基于受控 schema。
2. **一次操作可见的少字段 ≠ 删除重要原始字段。** Work Log 的隐藏辅助数值字段用于精确计算与可追溯。
3. **周期结转 ≠ 历史迁移。** 只保留明确确认的余额引用，不把旧工作全复制到新文件。
4. **App 差额 ≠ 逾期未付。** 即使 App 完全正确，结算批次也可能漏掉 Invoice。
5. **规则配置 ≠ 已确认政策。** 2h / 18:00 / 1.5× / Lunch 分配都是当前模型假设。
